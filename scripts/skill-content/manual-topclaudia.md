PERSONALIZAÇÕES (sem refazer tudo)
Se quiser mudar algo depois:
Mudar cor do dourado (ex: para rosa)
Busca #C9A227 e substitui por #FF69B4
Mudar cor do fundo (ex: para branco)
Busca #1C1C1C e substitui por #FFFFFF
Mudar tamanho de fonte (ex: de 90px para 80px)
Busca 90px e substitui por 80px
Mudar fonte (ex: de Georgia para Arial)
Busca Georgia e substitui por Arial

Onde fazer: Abra o HTML com Bloco de Notas/TextEdit → Ctrl+H (busca e substitui) → Salva → Atualiza navegador.


SALVAR COMO PNG (3 opções)
Opção 1: htmltopng.com (RECOMENDADO — mais fácil)
Acessa htmltopng.com
"Upload HTML file" → seleciona seu arquivo
"Download PNG"
Pronto (tamanho automático 1080×1350)
Opção 2: Print Screen + Paint (funciona mas dá trabalho)
Abre HTML no navegador
Print Screen
Abre Paint
Ctrl+V
Crop pra 1080×1350
Salva como PNG
Opção 3: Ferramenta online (https://pngquant.org)
Cola o HTML
Download automático

Recomendação: Use a opção 1 (htmltopng.com) — é a mais rápida.
